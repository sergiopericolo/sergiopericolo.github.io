Complex Operations and Annuities

Lectures 5–7 of Financial Mathematics (University of Brescia). Many amounts at many dates: how to value them at one date, and the special case where all payments have the same sign — the annuity. Compound interest throughout.

Roadmap:

  1. Valuing a complex operation — the value \(W(\hat t)\) at any date.
  2. Annuities — the classification.
  3. Ordinary annuity — \(a_{\overline{m}|i}\) and \(s_{\overline{m}|i}\).
  4. Annuity due, deferred and perpetual annuities.
  5. Finding the number of payments.

Complex financial operations

A complex operation is a set of pairs \((C_k, t_k)\), \(k = 0, 1, \dots, m\): amount \(C_k\) (positive if received, negative if paid) at date \(t_k\).

To value it at a date \(\hat t\), with \(t_h \le \hat t < t_{h+1}\), move every amount to \(\hat t\): accumulate the earlier ones with \(f\), discount the later ones with \(v\) (principle of financial equivalence):

\[W(\hat{t}) = \sum_{k=0}^{h} C_k f(\hat{t} - t_k) + \sum_{k=h+1}^{m} C_k v(t_k - \hat{t})\]

  • \(W(0)\) is the present value of the operation.
  • \(W(t_m)\) is its accumulated value.
  • The operation is fair if \(W(\hat t) = 0\) at some date. Under a separable law this holds at one date if and only if it holds at every date.

Annuities

An annuity is a complex operation whose amounts, the payments (rate), all have the same sign and fall at set dates. Classification:

Criterion Options
Periodicity periodic if the gap between payments (the period) is constant
Payment date ordinary (posticipata): end of each period; due (anticipata): start of each period
Start immediate: first period starts at \(t = 0\); deferred by \(p\) periods: starts at \(t = p\)
Length temporary: finite number of payments; perpetual: infinite

Ordinary immediate annuity

\(m\) constant payments \(R\) at the end of each period, from now on, at the periodic rate \(i\). Let \(v = (1+i)^{-1}\). The present value is a geometric series of ratio \(v\):

\[W(0) = Rv + Rv^2 + \dots + Rv^m = R \sum_{k=1}^{m} v^k = R \frac{1 - (1+i)^{-m}}{i}\]

The unit factor (\(R = 1\)) is the present value of an annuity-immediate:

\[a_{\overline{m}|i} = \frac{1 - (1+i)^{-m}}{i}\]

So \(W(0) = R \cdot a_{\overline{m}|i}\), located one period before the first payment.

By separability, the accumulated value at the last payment is \(W(0)(1+i)^m\):

\[W(m) = R \frac{(1+i)^m - 1}{i} = R \cdot s_{\overline{m}|i}, \qquad s_{\overline{m}|i} = \frac{(1+i)^m - 1}{i}\]

located at the last payment.

\(a_{\overline{m}|i}\) decreases in \(i\) (for fixed \(m\)) and increases in \(m\) (for fixed \(i\)).

Perpetuity

Let \(m \to +\infty\):

\[a_{\overline{\infty}|i} = \lim_{m \to +\infty} \frac{1 - (1+i)^{-m}}{i} = \frac{1}{i}, \qquad W(0) = \frac{R}{i}\]

A perpetuity has a finite present value but no accumulated value.

Annuity due

Payments at the start of each period. Each payment comes one period earlier than in the ordinary annuity, so accumulate by one period:

\[\ddot{a}_{\overline{m}|i} = (1+i) a_{\overline{m}|i}, \qquad \ddot{s}_{\overline{m}|i} = (1+i) s_{\overline{m}|i}\]

\(\ddot a\) sits at the first payment; \(\ddot s\) sits one period after the last payment. For a perpetuity due:

\[\ddot{a}_{\overline{\infty}|i} = 1 + \frac{1}{i} = \frac{1+i}{i}\]

Deferred annuities

Deferred by \(p\) periods: value the annuity at the start of its first period, then discount by \(p\) periods.

\[{}_{p|}a_{\overline{m}|i} = (1+i)^{-p} a_{\overline{m}|i}, \qquad {}_{p|}a_{\overline{\infty}|i} = \frac{(1+i)^{-p}}{i}\]

\[{}_{p|}\ddot{a}_{\overline{m}|i} = (1+i)^{-p} \ddot{a}_{\overline{m}|i} = (1+i)^{1-p} a_{\overline{m}|i}\]

The accumulated value of a deferred annuity equals that of the immediate one: deferral shifts the whole operation, not the distance between the payments and the final date.

Finding the number of payments

Given present value \(A\), payment \(R\) and rate \(i\), solve \(A = R \cdot a_{\overline{n}|i}\) for \(n\):

\[n = -\frac{\ln(1 - Ai/R)}{\ln(1+i)}\]

The log needs a positive argument, so a solution exists only if

\[A < \frac{R}{i}\]

The temporary annuity must be worth less than the perpetuity with the same payment and rate.

If \(n = n_0 + f\) is not an integer, one option is: pay \(n_0\) full payments \(R\), then a smaller final payment at \(n_0 + 1\). With \(A'\) the present value of the first \(n_0\) payments,

\[\tilde{R} = (A - A')(1+i)^{n_0+1}\]

Key takeaways

  • \(W(\hat t)\): accumulate the past amounts, discount the future ones. Fair \(\iff W = 0\).
  • \(a_{\overline{m}|i} = \frac{1 - (1+i)^{-m}}{i}\) (one period before the first payment); \(s_{\overline{m}|i} = \frac{(1+i)^m - 1}{i}\) (at the last payment).
  • Perpetuity: \(R/i\). Due: multiply by \((1+i)\). Deferred by \(p\): multiply by \((1+i)^{-p}\).
  • Number of payments: \(n = -\ln(1 - Ai/R)/\ln(1+i)\), requires \(A < R/i\).
